# 🌿 LeafLens – AI Vision-Based Plant Monitoring System

## 📌 Overview
LeafLens is an AI-powered plant monitoring system that detects plant diseases from leaf images using deep learning and computer vision. The system helps farmers identify plant health issues early and provides disease predictions through a user-friendly web interface.

---

## 🚀 Features

- 🌱 Detects plant diseases from leaf images
- 🤖 AI-based image classification using CNN
- 📷 Image upload for disease prediction
- 📊 Displays plant health status
- 🌐 Farmer-friendly web portal
- ⚡ Fast and accurate predictions
- 📈 Helps in early disease detection
- 💻 Simple and responsive user interface

## ⚙️ How It Works

1. User uploads a leaf image.
2. The image is preprocessed using OpenCV.
3. The trained CNN model analyzes the image.
4. The model predicts the plant disease.
5. The result is displayed on the web portal.
